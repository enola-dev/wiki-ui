Wiki UI Demo

This is an interactive fixture showcasing Wiki UI assets (CSS, syntax highlighting, and lazy-loaded Mermaid diagrams) matching Enola's md2html generation.

👉 View demo page without Mermaid (to verify in DevTools Network tab that mermaid.js is not loaded).

1. Syntax Highlighting

Syntax highlighting powered by highlight.js:

import hljs from 'highlight.js';

export async function init(): Promise<void> {
  hljs.highlightAll();

  if (typeof document !== 'undefined' && document.querySelector('pre.mermaid')) {
    const { renderMermaid } = await import(String('./mermaid.js'));
    await renderMermaid().catch(console.error);
  }
}

package dev.enola.wiki;

public final class WikiGenerator {
    public static void main(String[] args) {
        System.out.println("Enola Knowledge Base HTML Generation");
    }
}

2. Mermaid Diagrams (Lazy Loaded)

When <pre class="mermaid"> is present, mermaid.js is dynamically imported:

  B --> D[wiki.js]
  D -->|Lazy loaded on demand| E[mermaid.js]
  D -->|Included| F[highlight.js]

sequenceDiagram
  autonumber
  actor User
  participant Browser
  participant WikiJS as wiki.js
  participant MermaidJS as mermaid.js

  User->>Browser: Opens Wiki Page
  Browser->>WikiJS: Loads & executes init()
  WikiJS->>Browser: Runs syntax highlighting
  alt Has pre.mermaid
    WikiJS->>MermaidJS: Dynamic import('./mermaid.js')
    MermaidJS-->>WikiJS: renderMermaid()
    WikiJS->>Browser: Renders diagrams
  else No pre.mermaid
    WikiJS-->>Browser: Idle (no mermaid download)
  end
